## 🔧 前端API方法修复

### 🐛 **问题定位**
```javascript
// 错误信息
TypeError: window.apiClient.getMiAccounts is not a function
TypeError: window.apiClient.createMiAccount is not a function
```

### 🔍 **原因分析**
1. **方法被意外删除**: 关键的小米账户API方法从 `frontend/js/api.js` 中丢失
2. **方法重复定义**: 之前的修复导致方法重复，后续删除时过度清理

### ✅ **解决方案**

#### 1. **重新添加缺失的API方法**
```javascript
// 在 ApiClient 类中正确位置添加
// ===== 小米账户管理 =====

async getMiAccounts() {
    return await this.get('/mi-accounts');
}

async createMiAccount(accountData) {
    return await this.post('/mi-accounts', accountData);
}

async getMiAccountDetail(accountId) {
    return await this.get(`/mi-accounts/${accountId}`);
}

async updateMiAccount(accountId, accountData) {
    return await this.put(`/mi-accounts/${accountId}`, accountData);
}

async deleteMiAccount(accountId) {
    return await this.delete(`/mi-accounts/${accountId}`);
}

async syncMiAccount(accountId) {
    return await this.post(`/mi-accounts/${accountId}/sync`);
}
```

#### 2. **清理重复方法**
```bash
# 识别并删除重复的方法定义
grep -n "getMiAccounts\|createMiAccount" frontend/js/api.js
# 删除重复部分 (384-441行)
sed -i '' '384,441d' frontend/js/api.js
```

#### 3. **验证修复结果**
```bash
# 验证只有必要的方法存在
grep -c "getMiAccounts\|createMiAccount" frontend/js/api.js
# 输出: 2 (每个方法一个，正确!)
```
