# 小爱音箱API多用户平台升级方案

## 🎯 项目概述

将单用户的小爱音箱API升级为多用户SaaS平台，支持用户注册、设备绑定、API Key管理等功能。

## 🏗️ 系统架构升级

### 总体架构
```
用户前端 → Web管理平台 → API网关 → 核心服务 → 小米IoT设备
    ↑              ↑            ↑         ↑
  HTML页面     用户认证系统   API Key验证  设备管理服务
```

### 技术栈升级
- **后端框架**: FastAPI (保持)
- **数据库**: SQLite → PostgreSQL/MySQL (支持并发)
- **认证系统**: JWT + API Key双重认证
- **前端**: 响应式HTML5 + Bootstrap + JavaScript
- **缓存**: Redis (可选，用于session和设备状态缓存)

## 📊 数据库设计

### 用户表 (users)
```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    display_name VARCHAR(100),
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_login TIMESTAMP
);
```

### 小米账户配置表 (mi_accounts)
```sql
CREATE TABLE mi_accounts (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
    mi_username VARCHAR(100) NOT NULL,
    mi_password_encrypted TEXT NOT NULL,  -- 加密存储
    mi_device_id VARCHAR(100),
    mi_user_id VARCHAR(50),
    mi_pass_token TEXT,
    is_active BOOLEAN DEFAULT TRUE,
    last_sync TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 设备表 (devices)
```sql
CREATE TABLE devices (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
    device_id VARCHAR(100) NOT NULL,
    device_name VARCHAR(200) NOT NULL,
    device_model VARCHAR(100),
    device_status VARCHAR(20) DEFAULT 'unknown',
    volume INTEGER DEFAULT 80,
    location VARCHAR(100),
    is_favorite BOOLEAN DEFAULT FALSE,
    last_seen TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### API密钥表 (api_keys)
```sql
CREATE TABLE api_keys (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
    key_name VARCHAR(100) NOT NULL,
    api_key VARCHAR(64) UNIQUE NOT NULL,  -- UUID4格式
    is_active BOOLEAN DEFAULT TRUE,
    permissions TEXT,  -- JSON格式存储权限
    usage_count INTEGER DEFAULT 0,
    last_used TIMESTAMP,
    expires_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 使用记录表 (usage_logs)
```sql
CREATE TABLE usage_logs (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id),
    api_key_id INTEGER REFERENCES api_keys(id),
    device_id VARCHAR(100),
    action VARCHAR(50) NOT NULL,  -- speak, get_devices, etc.
    request_data TEXT,  -- JSON格式
    response_status INTEGER,
    execution_time FLOAT,
    ip_address INET,
    user_agent TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 🔐 认证与授权系统

### 双重认证机制
1. **Web管理界面**: JWT Token认证
2. **API调用**: API Key认证

### 权限级别
- **基础用户**: 最多3个设备，1000次/月API调用
- **高级用户**: 最多10个设备，10000次/月API调用
- **企业用户**: 无限设备，无限API调用

### API Key权限控制
```json
{
  "permissions": {
    "speak": true,
    "get_devices": true,
    "stop_speak": true,
    "set_volume": false
  },
  "rate_limit": {
    "requests_per_hour": 100,
    "requests_per_day": 1000
  }
}
```

- **调用统计**: API调用次数和趋势

- **错误日志**: 错误统计和分析
- **用量报告**: 月度使用报告

### 6. API文档模块
- **接口文档**: 完整的API使用说明
- **代码示例**: 多语言调用示例
- **在线测试**: 在线API测试工具
- **SDK下载**: 提供各语言SDK

## 🔄 业务流程设计

### 用户注册流程
1. **填写注册信息** → 验证邮箱 → 激活账户
2. **首次登录** → 引导绑定小米账户
3. **配置认证参数** → 获取设备列表
4. **创建API密钥** → 开始使用API

### 小米账户绑定流程
1. **输入小米账户** → 验证账户有效性
2. **自动获取认证参数** → 失败则提供手动输入
3. **测试连接** → 获取设备列表
4. **保存配置** → 定期同步设备状态

### API调用流程
1. **API Key验证** → 权限检查 → 用户限额检查
2. **设备权限验证** → 执行设备操作
3. **记录使用日志** → 更新统计数据

## 🚀 API接口升级

### 认证相关API
```python
POST /api/v1/auth/register          # 用户注册
POST /api/v1/auth/login             # 用户登录
POST /api/v1/auth/refresh           # 刷新Token
POST /api/v1/auth/logout            # 用户登出
POST /api/v1/auth/forgot-password   # 忘记密码
```

### 用户管理API
```python
GET  /api/v1/user/profile           # 获取用户信息
PUT  /api/v1/user/profile           # 更新用户信息
GET  /api/v1/user/statistics        # 用户使用统计
```

### 小米账户管理API
```python
GET  /api/v1/mi-accounts            # 获取小米账户列表
POST /api/v1/mi-accounts            # 添加小米账户
PUT  /api/v1/mi-accounts/{id}       # 更新小米账户
DELETE /api/v1/mi-accounts/{id}     # 删除小米账户
POST /api/v1/mi-accounts/{id}/sync  # 同步设备列表
POST /api/v1/mi-accounts/{id}/test  # 测试连接
```

### 设备管理API
```python
GET  /api/v1/devices                # 获取用户设备列表
GET  /api/v1/devices/{device_id}    # 获取设备详情
PUT  /api/v1/devices/{device_id}    # 更新设备信息
POST /api/v1/devices/{device_id}/test # 测试设备
```

### API密钥管理API
```python
GET  /api/v1/api-keys               # 获取API密钥列表
POST /api/v1/api-keys               # 创建API密钥
PUT  /api/v1/api-keys/{key_id}      # 更新API密钥
DELETE /api/v1/api-keys/{key_id}    # 删除API密钥
GET  /api/v1/api-keys/{key_id}/stats # 获取密钥统计
```

### 升级后的语音API (支持API Key认证)
```python
# 原有接口保持兼容，添加API Key认证
POST /api/v1/speak                  # 语音播放 (API Key认证)
GET  /api/v1/speak/status/{task_id} # 获取播放状态
POST /api/v1/speak/stop             # 停止播放
GET  /api/v1/public/devices         # 获取用户设备 (API Key认证)
```

## 🔧 技术实现要点

### 安全性增强
1. **密码加密**: bcrypt哈希存储
2. **数据加密**: 小米密码使用AES加密存储
3. **API限流**: 基于IP和用户的请求限制
4. **SQL注入防护**: 使用ORM参数化查询
5. **XSS防护**: 前端输入验证和转义

### 性能优化
1. **数据库索引**: 关键字段建立索引
2. **连接池**: 数据库连接池管理
3. **缓存策略**: Redis缓存热点数据
4. **异步处理**: 设备同步异步执行
5. **CDN加速**: 静态资源CDN分发

### 监控与日志
1. **应用监控**: 接口响应时间和错误率
2. **设备监控**: 设备在线状态监控
