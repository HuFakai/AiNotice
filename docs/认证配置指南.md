# 小米认证配置指南

## 概述

小爱音箱API支持两种认证方式：
1. **自动认证**：仅提供用户名和密码，系统自动处理认证过程
2. **手动认证**：提供完整的认证参数，提高认证稳定性和性能

## 配置项说明

### 基础配置（必需）
```env
MI_USER=your_xiaomi_username    # 小米账户用户名
MI_PASS=your_xiaomi_password    # 小米账户密码
```

### 高级配置（可选）
```env
MI_DEVICE_ID=your_device_id     # 设备ID
MI_USER_ID=your_user_id         # 用户ID  
MI_PASS_TOKEN=your_pass_token   # PassToken
```

## 配置方法

### 方法一：使用自动提取工具（推荐）

1. **运行认证管理工具**
```bash
python3 tools/mi_auth_manager.py
```

2. **按提示操作**
   - 工具会自动登录并提取认证信息
   - 询问是否自动更新 `.env` 文件
   - 选择 `y` 自动更新配置

3. **重启API服务**
```bash
python3 start.py
```

### 方法二：手动配置

1. **获取认证信息**
   - 可以从其他小米开发工具获取
   - 或从浏览器开发者工具中提取

2. **编辑 .env 文件**
```bash
nano .env
```

3. **添加认证参数**
```env
MI_DEVICE_ID=wb_eaf9fd19-c00e-4817-a639-70554d1170e2
MI_USER_ID=1506080450
MI_PASS_TOKEN=V1:DXmurwq2/R1BHTELu6obCWgBwabYkOzE3PPy81B/n8S...
```

## 认证参数说明

### Device ID
- **作用**：标识客户端设备
- **格式**：随机字符串，如 `wb_eaf9fd19-c00e-4817-a639-70554d1170e2`
- **获取**：系统自动生成或从已有会话提取

### User ID
- **作用**：小米用户的唯一标识
- **格式**：数字字符串，如 `1506080450`
- **获取**：登录成功后从响应中获取

### Pass Token
- **作用**：用户认证凭证
- **格式**：Base64编码的长字符串，以 `V1:` 开头
- **获取**：登录成功后从响应中获取
- **安全性**：包含敏感信息，请妥善保管

## 使用场景

### 开发环境
- 建议使用自动认证，配置简单
- 仅需配置 `MI_USER` 和 `MI_PASS`

### 生产环境
- 建议使用手动认证，提高稳定性
- 配置完整的认证参数，减少登录频率
- 可以避免频繁的认证请求被限制

### 多实例部署
- 每个实例使用不同的 `Device ID`
- 避免设备冲突和认证失败

## 故障排除

### 认证失败
1. **检查用户名密码**
   - 确认账户信息正确
   - 检查是否启用了二步验证

2. **检查认证参数**
   - 确认 Pass Token 未过期
   - 检查 Device ID 格式是否正确

3. **重新提取认证信息**
```bash
# 清除旧的认证缓存
rm -f .mi.token

# 重新运行认证工具
python3 tools/mi_auth_manager.py
```

### 设备ID冲突
- 不同实例使用不同的 `MI_DEVICE_ID`
- 避免多个服务使用相同的设备标识

### Token过期
- Pass Token 有有效期限制
- 定期重新提取认证信息
- 或清空配置让系统自动重新认证

## 安全建议

1. **保护认证信息**
   - 不要将 `.env` 文件提交到版本控制
   - 限制文件访问权限：`chmod 600 .env`

2. **定期更新**
   - 定期更新认证参数
   - 监控认证状态，及时处理异常

3. **环境隔离**
   - 不同环境使用不同的认证配置
   - 避免生产和测试环境混用

## 配置验证


   - 保存完整的认证参数

2. **生产部署**
   - 使用环境变量或配置管理工具

3. **监控告警**

   - 备份有效的认证配置
   - 准备快速恢复方案
