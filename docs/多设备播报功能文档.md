# 🔊 多设备播报功能 - 技术文档

## 📋 功能概述

多设备播报功能是小爱音箱API平台的重要升级，支持同时向多个小爱音箱设备播报相同内容，大幅提升了批量操作的效率和用户体验。

### 🎯 核心特性

- **🚀 并行执行**: 多设备任务同时启动，避免串行等待
- **🔄 向后兼容**: 完全兼容现有单设备API调用
- **📊 独立追踪**: 每个设备生成独立任务ID，便于状态监控
- **🛡️ 错误隔离**: 单个设备失败不影响其他设备播报
- **⚡ 高效处理**: 智能批量处理，减少API调用开销

## 🔧 技术实现

### API模型升级

#### SpeakRequest 模型
```python
class SpeakRequest(BaseModel):
    text: str = Field(..., description="要播放的文字内容")
    device_id: Optional[Union[str, List[str]]] = Field(
        None, 
        description="设备ID，支持单个字符串或字符串数组"
    )
    volume: Optional[int] = Field(None, ge=0, le=100, description="音量")
    speed: Optional[float] = Field(None, ge=0.5, le=2.0, description="语速")
```

#### SpeakResponse 模型
```python
class SpeakResponse(BaseModel):
    task_id: Optional[Union[str, List[str]]] = Field(
        None, 
        description="任务ID，单设备返回字符串，多设备返回字符串数组"
    )
    device_id: Optional[Union[str, List[str]]] = Field(
        None, 
        description="设备ID，与请求格式保持一致"
    )
    estimated_duration: Optional[float] = Field(
        None, 
        description="预估播放时长（秒）"
    )
```

### 服务层实现

#### 核心处理逻辑
```python
async def speak_text(self, request: SpeakRequest, user_id: str) -> SpeakResponse:
    # 统一处理单设备和多设备
    device_ids = [request.device_id] if isinstance(request.device_id, str) else request.device_id
    
    task_ids = []
    
    # 为每个设备创建独立任务
    for device_id in device_ids:
        task_id = f"speak_{uuid.uuid4().hex[:8]}_{int(time.time())}"
        
        # 创建任务状态
        await self._create_task_status(task_id, device_id, request.text, user_id)
        
        # 记录API调用日志
        await self._log_api_call(user_id, device_id, request.text)
        
        # 异步执行播放任务
        asyncio.create_task(self._execute_speak_task(task_id, device_id, request))
        
        task_ids.append(task_id)
    
    # 根据输入格式返回相应格式
    if isinstance(request.device_id, str):
        return SpeakResponse(
            task_id=task_ids[0],
            device_id=request.device_id,
            estimated_duration=self._estimate_duration(request.text)
        )
    else:
        return SpeakResponse(
            task_id=task_ids,
            device_id=device_ids,
            estimated_duration=self._estimate_duration(request.text)
        )
```

## 📖 使用指南

### 1. 单设备播报（向后兼容）

```bash
curl -X POST http://localhost:8000/api/v1/speak \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "欢迎使用小爱音箱API",
    "device_id": "xiaomi_speaker_001"
  }'
```

**响应示例**:
```json
{
  "task_id": "speak_a1b2c3d4_1703123456",
  "device_id": "xiaomi_speaker_001",
  "estimated_duration": 4.2
}
```

### 2. 多设备播报（新功能）

```bash
curl -X POST http://localhost:8000/api/v1/speak \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "紧急通知：会议将在5分钟后开始",
    "device_id": [
      "xiaomi_speaker_001",
      "xiaomi_speaker_002", 
      "xiaomi_speaker_003"
    ],
    "volume": 80
  }'
```

**响应示例**:
```json
{
  "task_id": [
    "speak_a1b2c3d4_1703123456",
    "speak_e5f6g7h8_1703123457",
    "speak_i9j0k1l2_1703123458"
  ],
  "device_id": [
    "xiaomi_speaker_001",
    "xiaomi_speaker_002",
    "xiaomi_speaker_003"
  ],
  "estimated_duration": 6.8
}
```

### 3. 任务状态查询

```bash
# 查询单个任务状态
curl -X GET http://localhost:8000/api/v1/speak/status/speak_a1b2c3d4_1703123456 \
  -H "Authorization: Bearer YOUR_API_KEY"

# 批量查询多个任务状态（需要多次调用）
for task_id in task_ids; do
  curl -X GET http://localhost:8000/api/v1/speak/status/$task_id \
    -H "Authorization: Bearer YOUR_API_KEY"
done
```

2. **错误处理**: 监控任务状态，及时处理失败设备
3. **网络优化**: 确保设备网络连接稳定
4. **内容优化**: 控制播报内容长度，避免过长文本

## 🔍 故障排查

### 常见问题

#### 1. 部分设备播报失败
**现象**: 多设备播报时，部分设备无响应
**排查步骤**:
1. 检查设备网络连接状态
2. 验证设备ID是否正确
3. 查看任务状态API获取详细错误信息
4. 检查设备是否处于勿扰模式

#### 2. 响应格式不符合预期
**现象**: 返回的task_id格式与预期不符
**解决方案**:
- 确认请求中device_id的格式（字符串 vs 数组）
- 响应格式会自动匹配请求格式

#### 3. 性能问题
**现象**: 大量设备播报时响应缓慢
**优化建议**:
- 分批处理大量设备
- 监控服务器资源使用情况
- 考虑增加并发限制
