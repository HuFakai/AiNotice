# 🚀 多设备播报功能 - 快速入门指南

## 🎯 功能简介

多设备播报功能允许您同时向多个小爱音箱设备播报相同内容，大幅提升批量操作效率。该功能完全向后兼容，现有的单设备API调用无需任何修改。

## ⚡ 快速开始

### 1. 基础用法对比

#### 单设备播报（原有功能）
```bash
curl -X POST "http://localhost:8000/api/v1/speak" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Hello World",
    "device_id": "device1"
  }'
```

#### 多设备播报（新功能）
```bash
curl -X POST "http://localhost:8000/api/v1/speak" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Hello World",
    "device_id": ["device1", "device2", "device3"]
  }'
```

### 2. 响应格式对比

#### 单设备响应
```json
{
  "task_id": "speak_a1b2c3d4_1703123456",
  "device_id": "device1",
  "estimated_duration": 3.5
}
```

#### 多设备响应
```json
{
  "task_id": [
    "speak_a1b2c3d4_1703123456",
    "speak_e5f6g7h8_1703123457",
    "speak_i9j0k1l2_1703123458"
  ],
  "device_id": ["device1", "device2", "device3"],
  "estimated_duration": 3.5
}
```

### 商业场所 - 营业提醒

```go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
    "os"
)

type SpeakRequest struct {
    Text     string   `json:"text"`
    DeviceID []string `json:"device_id"`
    Volume   int      `json:"volume"`
}

func main() {
    // 店铺各区域设备
    storeDevices := []string{
        "entrance_speaker",
        "cashier_speaker",
        "product_area_1",
        "product_area_2",
        "storage_room"
    }
    
    // 营业开始提醒
    request := SpeakRequest{
        Text:     "各位同事注意，店铺即将开始营业，请做好准备工作",
        DeviceID: storeDevices,
        Volume:   75,
    }
    
    jsonData, _ := json.Marshal(request)
    
    req, _ := http.NewRequest("POST", 
        "http://localhost:8000/api/v1/speak", 
        bytes.NewBuffer(jsonData))
    
    req.Header.Set("Content-Type", "application/json")
    req.Header.Set("Authorization", "Bearer "+os.Getenv("XAI_API_KEY"))
    
    client := &http.Client{}
    resp, err := client.Do(req)
    
    if err != nil {
        fmt.Printf("请求失败: %v\n", err)
        return
    }
    defer resp.Body.Close()
    
    fmt.Printf("营业提醒发送完成，状态码: %d\n", resp.StatusCode)
}
```

### Python批量状态查询

```python
import requests
import asyncio
import aiohttp

async def check_task_status(session, task_id, api_key):
    """异步查询单个任务状态"""
    url = f"http://localhost:8000/api/v1/speak/status/{task_id}"
    headers = {"Authorization": f"Bearer {api_key}"}
    
    async with session.get(url, headers=headers) as response:
        if response.status == 200:
            data = await response.json()
            return {
                "task_id": task_id,
                "status": data.get("status"),
                "device_id": data.get("device_id"),
                "progress": data.get("progress", 0)
            }
        else:
            return {"task_id": task_id, "error": f"HTTP {response.status}"}

async def monitor_multi_device_tasks(task_ids, api_key):
    """监控多设备播报任务状态"""
    async with aiohttp.ClientSession() as session:
        tasks = [check_task_status(session, task_id, api_key) for task_id in task_ids]
        results = await asyncio.gather(*tasks)
        
        print("多设备播报状态汇总:")
        for result in results:
            if "error" in result:
                print(f"❌ {result['task_id']}: {result['error']}")
            else:
                status_emoji = {
                    "pending": "⏳",
                    "playing": "🔊", 
                    "completed": "✅",
                    "failed": "❌"
                }.get(result["status"], "❓")
                
                print(f"{status_emoji} {result['device_id']}: {result['status']} ({result['progress']*100:.1f}%)")

# 使用示例
if __name__ == "__main__":
    # 从多设备播报响应中获取的任务ID列表
    task_ids = [
        "speak_a1b2c3d4_1703123456",
        "speak_e5f6g7h8_1703123457", 
        "speak_i9j0k1l2_1703123458"
    ]
    
    api_key = "your_api_key_here"
    asyncio.run(monitor_multi_device_tasks(task_ids, api_key))
```

```python
# 推荐：分批处理大量设备
def batch_speak(text, all_devices, batch_size=10):
    """分批处理大量设备播报"""
    for i in range(0, len(all_devices), batch_size):
        batch_devices = all_devices[i:i + batch_size]
        
        response = requests.post(
            "http://localhost:8000/api/v1/speak",
            headers={"Authorization": f"Bearer {api_key}"},
            json={
                "text": text,
                "device_id": batch_devices
            }
        )
        
        print(f"批次 {i//batch_size + 1}: 已发送到 {len(batch_devices)} 个设备")
        time.sleep(1)  # 避免过于频繁的请求
```

### 2. 错误处理和重试

```python
import time
from typing import List, Dict, Any

def robust_multi_speak(text: str, devices: List[str], max_retries: int = 3) -> Dict[str, Any]:
    """带重试机制的多设备播报"""
    for attempt in range(max_retries):
        try:
            response = requests.post(
                "http://localhost:8000/api/v1/speak",
                headers={
                    "Authorization": f"Bearer {api_key}",
                    "Content-Type": "application/json"
                },
                json={
                    "text": text,
                    "device_id": devices
                },
                timeout=30
            )
            
            if response.status_code == 200:
                return {
                    "success": True,
                    "data": response.json(),
                    "attempt": attempt + 1
                }
            else:
                print(f"尝试 {attempt + 1} 失败: HTTP {response.status_code}")
                
        except requests.exceptions.RequestException as e:
            print(f"尝试 {attempt + 1} 网络错误: {e}")
            
        if attempt < max_retries - 1:
            time.sleep(2 ** attempt)  # 指数退避
    
    return {
        "success": False,
        "error": f"重试 {max_retries} 次后仍然失败"
    }
```

## 🚨 常见问题解决

### Q1: 部分设备播报失败怎么办？

**A**: 多设备播报采用错误隔离设计，单个设备失败不影响其他设备。可以通过任务状态API查询具体失败原因：

```python
# 检查失败的设备并重试
failed_devices = []
for task_id in task_ids:
    status = get_task_status(task_id)
    if status["status"] == "failed":
        failed_devices.append(status["device_id"])

if failed_devices:
    print(f"重试失败的设备: {failed_devices}")
    robust_multi_speak(text, failed_devices)
```

### Q2: 如何优化大量设备的播报性能？

**A**: 建议采用分批处理策略：

```python
# 分批处理，每批最多20个设备
BATCH_SIZE = 20
for i in range(0, len(all_devices), BATCH_SIZE):
    batch = all_devices[i:i + BATCH_SIZE]
    batch_speak(text, batch)
    time.sleep(0.5)  # 批次间隔
```

### Q3: 响应格式不符合预期？

**A**: 响应格式会自动匹配请求格式：
- 请求 `device_id` 为字符串 → 返回单个 `task_id`
- 请求 `device_id` 为数组 → 返回 `task_id` 数组
