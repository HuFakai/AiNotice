## 📱 API端点总览

### 认证相关 (`/api/v1/auth`)
- `POST /register` - 用户注册
- `POST /login` - 用户登录  
- `POST /logout` - 用户登出
- `POST /verify` - 令牌验证
- `GET /me` - 获取当前用户
- `POST /check-username` - 检查用户名可用性
- `POST /check-email` - 检查邮箱可用性

### 用户管理 (`/api/v1/user`)
- `GET /profile` - 获取用户资料
- `PUT /profile` - 更新用户资料
- `POST /change-password` - 修改密码
- `GET /activities` - 获取活动记录
- `GET /stats` - 获取用户统计

### API密钥 (`/api/v1/api-keys`)
- `GET /` - 获取密钥列表
- `POST /` - 创建新密钥
- `PUT /{id}` - 更新密钥
- `DELETE /{id}` - 删除密钥

### 小爱设备 (兼容现有API)
- `GET /api/v1/health` - 健康检查
- `GET /api/v1/devices` - 获取设备列表
- `POST /api/v1/speak` - 语音播放 (支持单设备/多设备)
- `GET /api/v1/speak/status/{task_id}` - 获取任务状态

#### 🆕 多设备播报功能
**新增特性**: 支持同时向多个小爱音箱设备播报相同内容

**API参数升级**:
- `device_id`: 支持 `string` (单设备) 或 `string[]` (多设备)
- `task_id`: 返回 `string` (单任务) 或 `string[]` (多任务)

**使用示例**:
```bash
# 单设备播报 (向后兼容)
curl -X POST http://localhost:8000/api/v1/speak \
  -H "Authorization: Bearer API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Hello World",
    "device_id": "device1"
  }'

# 多设备播报 (新功能)
curl -X POST http://localhost:8000/api/v1/speak \
  -H "Authorization: Bearer API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Hello World",
    "device_id": ["device1", "device2", "device3"]
  }'
```

**响应格式**:
```json
// 单设备响应
{
  "task_id": "task_123",
  "device_id": "device1",
  "estimated_duration": 3.5
}

// 多设备响应
{
  "task_id": ["task_123", "task_124", "task_125"],
  "device_id": ["device1", "device2", "device3"],
  "estimated_duration": 3.5
}
```

**技术特性**:
- ✅ **并行执行**: 多设备任务同时启动，提高效率
- ✅ **独立任务**: 每个设备创建独立任务ID，便于状态追踪
- ✅ **向后兼容**: 完全兼容现有单设备API调用
- ✅ **错误隔离**: 单个设备失败不影响其他设备播报

## 🎯 使用方式

### 1. 用户注册和登录
```bash
# 注册新用户
curl -X POST http://localhost:8000/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "username": "demo_user",
    "email": "demo@xiaoai-api.com", 
    "password": "Demo123456",
    "display_name": "演示用户"
  }'

# 用户登录
curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username_or_email": "demo_user",
    "password": "Demo123456"
  }'
```

### 2. 使用JWT令牌
```bash
# 获取用户资料
curl -X GET http://localhost:8000/api/v1/user/profile \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```

### 3. 创建和使用API密钥
```bash
# 创建API密钥
curl -X POST http://localhost:8000/api/v1/api-keys \
  -H "Authorization: Bearer JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "key_name": "生产环境密钥",
    "permissions": {
      "speak": true,
      "get_devices": true,
      "manage_devices": false
    }
  }'

# 使用API密钥调用
curl -X GET http://localhost:8000/api/v1/devices \
  -H "Authorization: Bearer xai_sk_xxxxx"
```
