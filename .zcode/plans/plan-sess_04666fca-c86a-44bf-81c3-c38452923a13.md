## 一、绑定渠道下拉多选

**新建可复用组件 `components/MultiSelect.vue`**：
- Props：`modelValue`(数组) / `options`([{value,label,badge?,danger?}]) / `placeholder` / `disabled` / `loading` / `emptyText`
- 交互：触发框内以 tag 展示已选项（每项带 × 单独移除）；点击开合下拉面板；面板项 = 渠道名 + 类型徽章 + 选中 ✓（对齐截图）；点击外部自动关闭；键盘 Esc 关闭
- 样式：hairline 边框、`--font-mono`、badge 复用，浮层用深色面板 + 阴影，z-index 高于 Modal

**ApiKeysView.vue**：创建/编辑两处模态的 `channel-pick` checkbox 区块整体替换为 `<MultiSelect>`（选项由 `availableChannels` computed 生成）；卡片上的"推送渠道"徽章保留不变

## 二、接口测试标签页（API Playground）

**新增页面 `views/ApiTestView.vue`**，路由 `/api-test`，侧边栏 nav 编号 **09**（08=接口文档之后）。

**端点数据源抽取**：新建 `api/endpoints.js`——把 DocsView 里的 endpoints 表迁过去并**为每个端点补 body 示例**（如 /speak → `{"text": "你好", "device_id": "..."}`）；DocsView 改为引用同一数据源（单一真相，不再两处维护）

**页面布局**（左右两栏）：
- 左栏：端点列表（method 徽章 + 路径 + 所需权限位），点击选中
- 右栏请求区：
  - **认证方式**：默认「当前登录态(JWT)」；可切换「API 密钥」并粘贴完整密钥（**仅存页面内存，不写 localStorage/缓存**，刷新即失；文案说明原因——列表接口只回掩码，完整密钥只有创建时可见）
  - **路径/查询参数**：解析端点 path 中的 `{device_id}`/`{task_id}` 占位符与 `?volume=` 查询参数，生成输入框
  - **Body**：POST 端点自动预填该端点示例 JSON（可编辑 textarea）
  - 发送按钮 → 展示：状态徽章（2xx 绿 / 4xx 黄 / 5xx 红）、耗时 ms、**格式化 JSON 响应体**（`<pre>` 模板插值 + CopyButton；含 4xx 的 detail 错误信息）
- **会话内历史**：最近 20 次调用（方法/路径/状态/耗时），点击回填表单
- 细节：用独立 fetch（不走 client.js，避免 401 触发全局跳登录）；会真实控制设备的端点在 desc 已说明

**接线**：router 加 `/api-test` 路由（nav: '09'）；AppShell 导航数组追加「接口测试」项
