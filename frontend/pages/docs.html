使用 API 密钥调用小爱音箱 API

本页提供多语言代码示例，展示如何在服务器端或受信任环境中使用 API 密钥（API Key）访问平台接口。

说明：服务器端推荐在 Authorization 头中携带 API Key。支持格式：Bearer xai_sk_...、ApiKey xai_sk_... 或直接 xai_sk_...。
基础信息
  • API 基础地址：http://localhost:8000/api/v1
  • 认证方式：在 Authorization 请求头中携带 API Key
  • 示例接口：GET /devices（获取设备列表），POST /speak（指定设备播放文字）
安全提示：请仅在后端服务或可信执行环境中使用 API Key，避免在浏览器前端直接暴露。
准备工作
环境变量

以下示例均假设你已将 API Key 配置到环境变量：

# macOS / Linux（建议写入~/.zshrc 或服务进程环境）
export XAI_API_URL=http://localhost:8000/api/v1
export XAI_API_KEY="xai_sk_xxxxxxxxxxxxxxxxxxxxxx"

# Windows PowerShell
$env:XAI_API_URL="http://localhost:8000/api/v1"
$env:XAI_API_KEY="xai_sk_xxxxxxxxxxxxxxxxxxxxxx"
获取设备列表（GET /devices）
curl
curl -s -X GET "$XAI_API_URL/devices" \
  -H "Authorization: Bearer $XAI_API_KEY"
Python (requests)
import os, requests
url = f"{os.getenv('XAI_API_URL')}/devices"
headers = {"Authorization": f"Bearer {os.getenv('XAI_API_KEY')}"}
r = requests.get(url, headers=headers, timeout=10)
print(r.status_code, r.json())
Node.js (axios)
const axios = require('axios');
const baseURL = process.env.XAI_API_URL;
const apiKey = process.env.XAI_API_KEY;

axios.get(`${baseURL}/devices`, {
  headers: { Authorization: `Bearer ${apiKey}` }
}).then(res => console.log(res.data))
  .catch(err => console.error(err.response?.data || err.message));
Go (net/http)
package main
import (
  "fmt"
  "net/http"
  "os"
  "io/ioutil"
)
func main() {
  url := os.Getenv("XAI_API_URL") + "/devices"
  req, _ := http.NewRequest("GET", url, nil)
  req.Header.Set("Authorization", "Bearer "+os.Getenv("XAI_API_KEY"))
  resp, err := http.DefaultClient.Do(req)
  if err != nil { panic(err) }
  defer resp.Body.Close()
  body, _ := ioutil.ReadAll(resp.Body)
  fmt.Println(resp.StatusCode, string(body))
}
Java (OkHttp)
OkHttpClient client = new OkHttpClient();
Request request = new Request.Builder()
    .url(System.getenv("XAI_API_URL") + "/devices")
    .addHeader("Authorization", "Bearer " + System.getenv("XAI_API_KEY"))
    .build();
try (Response res = client.newCall(request).execute()) {
  System.out.println(res.code());
  System.out.println(res.body().string());
}
PHP (cURL)
设备播放文字（POST /speak）- 支持多设备

支持单设备和多设备播报。请求体需要包含 text（要播放的文字）与 device_id（设备ID）。device_id 支持字符串（单设备）或字符串数组（多设备）格式。可选参数包括 volume（音量，0-100）和 endvolume（播放结束后音量，0-100）。

🆕 多设备播报特性
  • ✅ 并行执行：多设备任务同时启动，提高效率
  • ✅ 独立任务：每个设备创建独立任务ID，便于状态追踪
  • ✅ 向后兼容：完全兼容现有单设备API调用
  • ✅ 错误隔离：单个设备失败不影响其他设备播报

curl -s -X POST "$XAI_API_URL/speak" \
  -H "Content-Type: application/json" \

  -d '{

Go (net/http)
package main
import (
  "bytes"; "fmt"; "net/http"; "os"; "io/ioutil"
)
func main(){
  url := os.Getenv("XAI_API_URL") + "/speak"
  body := []byte(`{"text":"你好，这是测试播放","device_id":"445777160"}`)
  req, _ := http.NewRequest("POST", url, bytes.NewBuffer(body))
  req.Header.Set("Content-Type","application/json")
  req.Header.Set("Authorization","Bearer "+os.Getenv("XAI_API_KEY"))
  resp, err := http.DefaultClient.Do(req)
  if err != nil { panic(err) }
  defer resp.Body.Close(); b,_ := ioutil.ReadAll(resp.Body); fmt.Println(string(b))
}

音量控制参数说明
参数详情
  • volume（可选）：播放时的音量，取值范围 0-100，默认为设备当前音量
  • endvolume（可选）：播放结束后恢复的音量，取值范围 0-100，默认保持播放时音量
使用场景：可以在播放重要通知时临时提高音量，播放结束后自动恢复到合适的音量。
错误处理
  • 401 Unauthorized：API Key 无效或缺失。请检查 Authorization 头。
  • 403 Forbidden：权限不足。请在平台里为密钥开启对应权限（如 get_devices、speak）。
  • 429 Too Many Requests：请求过于频繁。请降低调用频率或联系管理员。
常见问题
  • 设备ID如何获取？ 通过 GET /devices 接口获取。也可在“设备管理”页面一键复制。
  • 为何不建议前端直接用 API Key？ API Key 与账户绑定，具备权限，暴露风险高。建议仅用于后端对后端（B2B/BFF）。
  • 是否支持 HTTPS？ 生产环境强烈建议启用 HTTPS 并配置 CORS 白名单。
